מסך בית הכנסת – שמירה וסנכרון מרכזיים ב-Google Drive
======================================================

מה תוקן
-------
- כתובת Google Apps Script יכולה להיות מוגדרת בקובץ index.html עצמו, ולא רק ב-localStorage של דפדפן מסוים.
- לאחר הגדרה זו כל מחשב/טלפון וכל דפדפן שפותחים בהם את אותו אתר מתחברים לאותו קובץ synagogue-config.json ב-Google Drive.
- כפתור "משיכה מהענן עכשיו" שומר גם את כתובת הענן בדפדפן הנוכחי.
- נשמר מנגנון הסנכרון הקיים: טעינה אוטומטית בפתיחת האתר, בדיקה תקופתית ושמירה לאחר לחיצה על "שמירה".
- נוספה נעילה בשרת כדי לצמצם התנגשויות כאשר שתי שמירות מתבצעות במקביל.

התקנה חד-פעמית (נדרשת כדי שהמערכת תעבוד בכל דפדפן)
---------------------------------------------------
1. פתחו https://script.google.com/ והיכנסו לפרויקט Apps Script שבו נמצא Code.gs.
2. החליפו בראש Code.gs את CHANGE-THIS-TO-A-LONG-UNIQUE-PASSWORD בסיסמה חזקה וייחודית שאתם שומרים במקום בטוח.
3. הדביקו/עדכנו את כל תוכן Code.gs ושמרו.
4. Deploy -> Manage deployments -> Edit (עיפרון) -> Version: New version -> Deploy. אם אין פריסה קיימת: Deploy -> New deployment -> Web app.
5. הגדרות הפריסה: Execute as: Me. Who has access: Anyone. ההרשאה Anyone נחוצה כדי שמסכי התצוגה יוכלו לקרוא את הנתונים; כתיבה מוגנת בסיסמה.
6. העתיקו את כתובת ה-Web app שמסתיימת ב-/exec.
7. כתובת ה-Web App שסיפקתם כבר משולבת בקובץ index.html בשורה CLOUD_API_URL. אין צורך להדביק אותה שוב.
8. העלו מחדש את index.html ואת sw.js לאותו אחסון שבו נמצא האתר (Netlify / GitHub Pages או השרת שלכם).
9. פתחו את האתר, היכנסו לניהול, ובדקו שמופיע "ענן: מסונכרן". בשמירה הראשונה תתבקשו להזין את הסיסמה שהגדרתם ב-Code.gs.
10. פתחו את אותו אתר מדפדפן או מכשיר אחר. הוא אמור לטעון את אותה תצורה מה-Drive ללא הגדרה מקומית נוספת.

חשוב לדעת
----------
- כתובת ה-Web App שסיפקתם משולבת בקובץ index.html. עדיין נדרש לוודא ש-Code.gs המעודכן פרוס בכתובת הזו ושסיסמת הניהול הוגדרה בו.
- אין להכניס את סיסמת הניהול לתוך index.html. רק כתובת ה-/exec מוגדרת שם; הסיסמה מתבקשת בעת שמירה.
- לאחר שינוי Code.gs חובה לפרוס New version. שמירת הקוד בעורך לבדה אינה מעדכנת את כתובת ה-Web app שכבר פורסמה.
- הנתונים נקראים מכל מי שיכול להגיע לכתובת ה-Web app, לכן אל תשמרו בקובץ פרטים פרטיים/רגישים.
- אם משתמשים בכתובת ?api=... הישנה, היא עדיין נתמכת, אך ההגדרה הקבועה בקובץ עדיפה כדי שכל דפדפן יתחבר אוטומטית.
